## JUCE

- GitHub releases showed JUCE Version 8.0.12 dated Dec 16, 2025.
- JUCE GitHub project describes JUCE as a cross-platform framework for desktop/mobile apps including VST, VST3, AU, AUv3, AAX, and LV2 plugins, and supports CMake integration.
- JUCE CMake API docs list plugin target formats including VST3.
- JUCE MP3AudioFormat docs contain an explicit disclaimer for enabling software MP3 decoding.
